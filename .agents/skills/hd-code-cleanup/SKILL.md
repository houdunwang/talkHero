# 后盾云代码清理

模式一处理未使用资产，模式二简化仍在使用的冗余代码，用户要求全面清理时依次执行两者。只要求检查、审计或列候选时保持只读；明确要求清理、删除、移除或简化时才在用户指定范围实施。未给可操作范围时先要求范围，不因全仓搜索扩大修改范围。

运行前完整读取 `../../../AGENTS.md`、相关模块 README、Spec/Plan 与 Git 状态，保护无关改动。静态分析和 `rg` 只产生候选，删除前交叉检查 TypeScript import、动态 import、字符串 IPC channel、TanStack 生成路由、`config/` 装配、Electron 生命周期副作用、preload bridge、Tray/菜单/窗口注册、electron-builder 资源、原生 addon、PowerShell worker、脚本、测试和文档引用。

优先顺序：局部变量/导入 → 私有函数/类型/内部导出 → 内部模块/文件 → 资源/脚本/配置 → 公共 API、路由、IPC、持久化字段和依赖。公开导出、框架入口、`src/renderer/routeTree.gen.ts`、生成目录、兼容层、数据字段、签名/安装/更新资源或原生构建资产没有充分证据不得删除。

边界层的用户/网络/IPC/文件/持久化/权限/支付/系统 API 校验、错误转换和资源清理必须保留。内部层只在数据流证明上游已保证时删除重复判断、无意义默认值、吞错 `try/catch`、单纯转发层或假设性扩展点。每项说明冗余证据、行为等价依据、验证方式与未排除风险；证据不足标记“保留/待确认”。

依赖只有在源码、脚本、测试、构建、插件和发布均无用途时才可用 pnpm 原生命令移除并同步锁文件；不得手改锁文件或顺带升级。验证从目标测试和相关回归开始，再按风险运行 `pnpm typecheck`、`pnpm lint`、必要构建与真实桌面验证，最后检查 diff/Git 状态。不得弱化测试或执行全仓格式化。

输出已删除/简化项及证据、保留或待确认项、实际验证和结论。安装本 Skill 不代表执行代码清理。
